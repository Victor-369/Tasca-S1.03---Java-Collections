# Tasca S1.03 — Java Collections

Java collection exercises covering lists, iterators, sets, maps, and comparators.
Each exercise has its own README with a description and usage notes:

| Exercise | Topic | Documentation |
| --- | --- | --- |

| Nivell 1, exercici 2 | `ListIterator` and list manipulation | [README](src/main/java/com/pruebas/proyecto/nivell1/exercici2/README.md) |
| Nivell 1, exercici 3 | Country-capital quiz, file input, and `HashMap` | [README](src/main/java/com/pruebas/proyecto/nivell1/exercici3/README.md) |
| Nivell 2, exercici 1 | `HashSet` and restaurant equality | [README](src/main/java/com/pruebas/proyecto/nivell2/exercici1/README.md) |
| Nivell 2, exercici 2 | Restaurant ordering with multiple criteria | [README](src/main/java/com/pruebas/proyecto/nivell2/exercici2/README.md) |

The Maven project is configured for Java 25. For exercises that read or write
data files, run the program with the project root as its working directory.
